# ShopNest E-Commerce Frontend

Frontend-only e-commerce demo built with HTML, CSS and Vanilla JavaScript.

## Features
- Responsive design
- Product listing
- Search
- Category filtering
- Product detail modal
- Wishlist
- Shopping cart
- Quantity controls
- LocalStorage cart persistence
- Dark mode
- Newsletter demo
- Frontend checkout
- Automatic order receipt
- Receipt item/quantity/price breakdown
- Print / Save receipt as PDF
- Coupon system
- Percentage coupons
- Fixed-amount coupons
- Free-shipping coupon
- Coupon discount shown in cart
- Coupon discount shown on receipt

## Demo coupon codes

- WELCOME10 = 10% OFF
- SHOP20 = 20% OFF
- SAVE200 = ₹200 OFF
- FREESHIP = FREE SHIPPING

## Run
Open `index.html` in a browser.

No backend, database, authentication, or real payment gateway is included.
For production, validate coupons on a backend/server rather than trusting browser-side JavaScript.


## Login & Sign Up

Added frontend-only authentication:
- Login
- Sign Up
- Confirm password
- Remember me
- Logout
- Account panel
- Basic account avatar
- LocalStorage user data
- Login state persists in the browser

Demo note:
This is NOT secure production authentication. Passwords are stored in browser localStorage for demonstration only. A real e-commerce site must use a backend with hashed passwords, secure sessions/tokens, HTTPS, validation, rate limiting, and server-side authorization.
